# Cha Tara

Мобильное чайное приложение на Flutter. Каталог, заметки о заваривании и дневник сессий. Данные дневника хранятся в браузере устройства. Мастер Чи и социальная лента обозначены как направления дальнейшего развития.

## Запуск

Установите Flutter, затем выполните `flutter create --platforms=web .`, `flutter pub get` и `flutter run -d chrome`. Для публикации GitHub Actions собирает Flutter Web и отправляет результат в GitHub Pages.
